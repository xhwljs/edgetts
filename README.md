# 🧮 数学乐园 - 儿童数学学习软件

一款专为一二年级孩子设计的本地数学学习软件，支持口算、填空等多种题型，无需联网即可运行。

## ✨ 功能特点

### 🎯 核心功能
- **口算练习**：支持0-10、0-20、0-50、0-100四个难度档位
- **填空练习**：在算式的不同位置设置空缺，锻炼逆向思维
- **混合运算**：自动生成加法、减法混合题目
- **随机练习**：随机组合不同题型，保证每种题型至少出一道

### 🏆 挑战模式
- 按难度分为四个大关卡组（入门篇、基础篇、进阶篇、高级篇）
- 每个大组包含5个递进小关卡
- 每关10道题，全对解锁下一关
- 支持答错重试

### 📚 错题整理
- 自动记录错题，方便复习
- 显示用户答案和正确答案对比
- 支持清空错题本

### 👨‍👩‍👧 家长模式
- 查看孩子的学习统计（练习次数、答对题数、正确率等）
- 查看练习历史记录
- 支持导出学习数据

### 🎨 主题商店
- 多种精美主题皮肤可选
- 通过练习获得积分兑换主题

### 🏅 勋章系统
- 完成特定成就解锁勋章
- 激励孩子持续学习

## 🚀 部署方式

### 方式一：直接打开（推荐）

1. 下载或克隆项目到本地
2. 双击打开 `index.html` 文件
3. 在浏览器中直接运行（推荐使用 Chrome 或 Firefox）

### 方式二：本地Web服务器

#### 使用 Python（推荐）

```bash
# Python 2
python -m SimpleHTTPServer 8000

# Python 3
python -m http.server 8000
```

然后访问 http://localhost:8000

#### 使用 Node.js

```bash
npm install -g http-server
http-server -p 8000
```

然后访问 http://localhost:8000

#### 使用 Termux（手机端）

```bash
pkg install git python
git clone <仓库地址>
cd math-land
python -m http.server 8080
```

然后在手机浏览器中访问 http://localhost:8080

## 🎮 使用说明

1. **首页**：点击「自定义练习」「随机混合练习」或「挑战模式」开始
2. **自定义练习**：选择题型（口算/填空）、难度、运算类型后开始
3. **答题**：在输入框中输入答案，按回车键或点击提交按钮
4. **结算页面**：查看答对题数、用时和获得的积分
5. **错题本**：查看和复习错题
6. **家长模式**：查看学习统计和历史记录
